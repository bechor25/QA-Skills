# Trigger phrases

The `test-orchestrator` skill activates on these phrases (case-insensitive):

## English
- `run qa`
- `qa run`
- `generate tests`
- `generate tests for my project`
- `full qa run`

## Hebrew
- `הרץ qa`
- `הרץ בדיקות`
- `צור בדיקות`
- `צור בדיקות לפרויקט שלי`
